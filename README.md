# AntiGod GRUB Theme

An original GRUB bootloader theme designed and built from scratch.

![Preview](Preview.png)

## About

AntiGod is a custom GRUB bootloader theme created as a personal Linux customization project. It features an original visual design built to provide a distinctive boot menu experience.

The theme is currently usable and continues to evolve as its design and features are refined.

### 📥 Installation

1. Clone this repository:
```bash
git clone https://github.com/Mora-project-ui/AntiGod-Grub-theme.git
cd AntiGod-Grub-theme
```

2. Run the installer script:
```bash
chmod +x install.sh
sudo ./install.sh
```

3. Reboot your system to see your new new GRUB theme!
